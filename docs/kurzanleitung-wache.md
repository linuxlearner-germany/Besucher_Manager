## Normaler Ablauf

**Anmelden → richtige Wache → Besucher suchen → prüfen → einchecken → drucken → auschecken → abmelden**

### Normaler Check-in

**Wache → Tagesliste → Suche → Details → Einchecken → Drucken**

- ☐ Richtige Person und Anmeldung
- ☐ Identität, Gültigkeit, Wache und Ansprechpartner geprüft
- ☐ **Prüfung** ohne blockierende Pflichtfelder
- ☐ Besucherschein vor Ausgabe kontrolliert

### Spontanbesuch

**Wache → Spontanbesucher anmelden → vorhandenen Besucher suchen → erfassen → Abschlussaktion**

- Erst nach vorhandenem Besucher suchen; Dubletten vermeiden.
- Wache, Gültigkeit, Besuchszweck und Ansprechpartner prüfen.
- Passende Aktion wählen: nur speichern / einchecken / einchecken und drucken.

### Check-out

**Wache → Eingecheckt → richtiger Besuch → Besuchsnummer → Bestätigung → Auschecken**

- ☐ Richtige Person
- ☐ Besucherschein und Besuchsnummer geprüft
- ☐ Ansprechpartner-Bestätigung liegt vor
- ☐ Erst danach ausgecheckt

## Problemfall

**Nicht raten, keine Ersatzbuchung anlegen und keine Daten erfinden.**

| Fall | Maßnahme |
|---|---|
| Falsche Person ein-/ausgecheckt | Stoppen; Wachleitung und fachliche Stelle informieren |
| Besucherschein fehlt | Nicht regulär auschecken; nach Dienstanweisung klären |
| Ansprechpartner nicht erreichbar | Nicht ohne Klärung einlassen; Wachleitung einschalten |
| Falsche Wache | Abmelden und mit richtiger Wache neu anmelden |
| Systemausfall | IT/Wachleitung melden; nur freigegebenen Notbetrieb nutzen |
